# Prime Number Checker 🔢🔍

An efficient program designed to check whether a given integer is a **Prime Number** or not. A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself (e.g., `2`, `3`, `5`, `7`, `11`, etc.).

---

## 🌟 Key Features

- **Instant Primality Test:** Rapidly checks if an entered number is prime.
- **Range Generator:** (If applicable) Generates a list of all prime numbers between a specific range (e.g., 1 to 100).
- **Optimized Algorithm:** Implements efficient mathematical logic (like checking divisors up to $\sqrt{n}$) to minimize execution time for larger numbers.
- **Clean Input Validation:** Handles negative numbers, 0, and 1 gracefully with proper user messaging.
